# 📚 Book Template Builder - Cursor Integration

## 🎯 **Expert Book Template Builder for Writing Apps**

A comprehensive system for creating customizable book templates in Cursor. Generate professional templates for novels, non-fiction, poetry, and any genre with flexible structures and exportable formats.

---

## 🚀 **Quick Start Guide**

### **Using in Cursor Composer**
1. **Open Cursor Composer** (Cmd+I)
2. **Select your target folder** for the template
3. **Use the prompt**: "Generate book template for [genre] with [structure]"
4. **Customize** the generated template with your specific needs

### **Using in Cursor Rules**
1. **Create file**: `.cursor/rules/book-template-builder.mdc`
2. **Copy the rules** from the rules file
3. **Use Cmd+K** to generate templates
4. **Refine** with YOLO mode for rapid iteration
