# 🚀 Quick Start Guide - Book Template Builder for Cursor

## 🎯 **Get Started in 5 Minutes**

This guide will help you set up and use the Book Template Builder in Cursor to generate professional book templates for any genre.

---

## 📋 **Setup Instructions**

### **Step 1: Create Cursor Rules File**
1. **Open your project** in Cursor
2. **Create folder**: `.cursor` (if it doesn't exist)
3. **Create file**: `.cursor/rules/book-template-builder.mdc`
4. **Copy the rules** from `CURSOR_RULES.md` into this file

### **Step 2: Test the Integration**
1. **Open Cursor Composer** (Cmd+I)
2. **Type prompt**: "Generate fantasy novel template"
3. **Verify** that the AI generates a structured template
4. **Test Cmd+K** to ensure rules are working

---

## 🚀 **Quick Template Generation**

### **Method 1: Cursor Composer (Cmd+I)**
1. **Open Composer** with Cmd+I
2. **Select target folder** for your template
3. **Use this prompt**:
   ```
   Generate book template for [GENRE] with [STRUCTURE] including:
   - Chapter prompts with specific guidance
   - Character development sheets
   - Progress tracking system
   - Exportable to DOCX format
   ```

### **Method 2: Cursor Rules (Cmd+K)**
1. **Select files** where you want the template
2. **Press Cmd+K** to open AI chat
3. **Use this prompt**:
   ```
   Create [GENRE] book template with [STRUCTURE] structure
   ```

### **Method 3: YOLO Mode (Rapid Iteration)**
1. **Generate initial template** using above methods
2. **Select the generated template**
3. **Use Cmd+K** to refine and improve
4. **Iterate quickly** until satisfied

## 🎯 **Quick Reference**

### **Essential Commands**
- **Cmd+I**: Open Cursor Composer
- **Cmd+K**: Open AI chat with rules
- **Cmd+Shift+P**: Command palette
- **Cmd+S**: Save current file

### **Essential Prompts**
- **"Generate [genre] template"**: Basic template generation
- **"Customize template for [specific needs]"**: Template customization
- **"Add [feature] to template"**: Feature addition
- **"Export template to [format]"**: Format conversion

### **Essential Variables**
- **{{Title}}**: Book title
- **{{Author}}**: Author name
- **{{Genre}}**: Book genre
- **{{Word_Count}}**: Target word count
- **{{Chapter_Count}}**: Number of chapters
