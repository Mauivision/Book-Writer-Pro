# 📚 Book Template Generator - Cursor Integration

## 🎯 **Expert Book Template Builder for Writing Apps**

Generate customizable templates for novels, non-fiction, poetry, and any genre with flexible structures and exportable formats.

---

## 🚀 **Template Generation System**

### **Input Parameters**
- **Genre**: fantasy, sci-fi, romance, mystery, non-fiction, poetry, etc.
- **Structure**: 3-act, 5-act, hero's journey, memoir, academic, etc.
- **Elements**: chapters, outlines, character sheets, world-building, etc.
- **Format**: markdown, JSON, DOCX exportable
- **Variables**: {{character_name}}, {{setting}}, {{theme}}, etc.

### **Output Features**
- **Markdown/JSON templates** with structured sections
- **Chapter prompts** with specific guidance
- **Variable placeholders** for customization
- **Progress trackers** and milestone systems
- **SEO-friendly metadata** and descriptions
- **Exportable formats** (DOCX via Pandoc)
