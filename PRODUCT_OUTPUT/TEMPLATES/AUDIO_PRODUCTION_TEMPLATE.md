## 🎯 Distribution Strategy Template

### Platform-Specific Requirements
#### Audible (ACX)
- [ ] **File Format**: MP3 or M4A
- [ ] **Sample Rate**: 44.1 kHz
- [ ] **Bit Rate**: 64 kbps (mono) or 128 kbps (stereo)
- [ ] **Chapter Markers**: Required
- [ ] **Cover Art**: 2400x2400 pixels minimum

#### Libro.fm
- [ ] **File Format**: MP3 or M4B
- [ ] **Sample Rate**: 44.1 kHz
- [ ] **Bit Rate**: 128 kbps minimum
- [ ] **Chapter Markers**: Recommended
- [ ] **Cover Art**: 2400x2400 pixels minimum

#### Apple Books Audio
- [ ] **File Format**: M4B
- [ ] **Sample Rate**: 44.1 kHz
- [ ] **Bit Rate**: 64-320 kbps
- [ ] **Chapter Markers**: Required
- [ ] **Cover Art**: 2400x2400 pixels minimum
