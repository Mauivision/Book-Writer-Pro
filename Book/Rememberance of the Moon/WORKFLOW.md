## **🔄 Core Workflow Process**

### **Chapter Expansion Process**

#### **Step 1: Pre-Expansion Preparation**
```
┌─────────────────┐    ┌──────────────────┐    ┌─────────────────┐
│   Chapter       │───▶│   Character      │───▶│   Quality       │
│   Analysis      │    │   Voice Check    │    │   Checklist     │
└─────────────────┘    └──────────────────┘    └─────────────────┘
```

**Tasks:**
- [ ] Review original transcript for plot points
- [ ] Note character voices and development opportunities
- [ ] Identify sensory details to expand
- [ ] Mark mystery elements to enhance

#### **Step 2: AI Expansion**
```
┌─────────────────┐    ┌──────────────────┐    ┌─────────────────┐
│   Use Standard  │───▶│   Expand to      │───▶│   Initial       │
│   Prompt        │    │   1,500-2,000    │    │   Review        │

**Standard Prompt:**
```
Take this spoken transcript of a sci-fi novel. Expand each chapter to 1,500–2,000 words. Keep the plot, but add longer descriptions, internal monologues, sensory details, dialogue beats. Make Zara's voice sharper, ALEX more human, the mystery creepier. Output as clean prose, no parentheses, no stage directions.
```

#### **Step 3: Human Review & Revision**
```
┌─────────────────┐    ┌──────────────────┐    ┌─────────────────┐
│   Read for      │───▶│   Character      │───▶│   Technical     │
│   Flow & Voice  │    │   Consistency    │    │   Polish        │
└─────────────────┘    └──────────────────┘    └─────────────────┘
```

**Review Checklist:**
- [ ] Character voices match guidelines
- [ ] Word count targets met
- [ ] Plot structure maintained
- [ ] Sensory details enhanced
- [ ] Mystery elements creepy/atmospheric
- [ ] Clean prose without stage directions

#### **Step 4: Quality Gates**
```
┌─────────────────┐    ┌──────────────────┐    ┌─────────────────┐

## **🤝 Collaboration Process**

### **Communication Protocol**

#### **Daily Check-ins**
- **Time**: 9:00 AM EST
- **Format**: Brief status update
- **Content**:
  ```
  📈 Progress: Chapter 2 expansion - 1,200/1,500 words
  🎯 Today: Complete Chapter 2, start Chapter 3
  🚧 Issues: Need help with physics descriptions
  💡 Ideas: Consider adding more ALEX internal conflict
  ```

#### **Feedback Loops**
```
┌─────────────────┐    ┌──────────────────┐    ┌─────────────────┐
│   Share Draft   │───▶│   Review &       │───▶│   Discuss       │
│                 │    │   Feedback       │    │   Changes       │
└─────────────────┘    └──────────────────┘    └─────────────────┘
```

**Feedback Guidelines:**
1. **Specific**: Point to exact lines/issues
2. **Constructive**: Focus on improvement, not criticism
3. **Actionable**: Suggest specific fixes
4. **Prioritized**: Separate major vs. minor issues

### **Decision Making**
- **Small Decisions**: Make independently, inform later
- **Medium Decisions**: Quick consultation via chat
- **Major Decisions**: Scheduled discussion with pros/cons
- **Creative Disagreements**: Try both approaches, compare results

## **✨ Quality Control**

### **Standard Operating Procedures**

#### **Chapter Quality Gates**
1. **Draft Completion**: Meets word count and basic structure
2. **Self-Review**: Author reads for flow and voice
3. **Technical Check**: Grammar, spelling, consistency
4. **Character Check**: Voices match established guidelines
5. **Plot Check**: Maintains original structure and mystery
6. **Final Polish**: Last pass for prose quality

#### **Consistency Checks**
- **Character Voices**: Use character voice profiles as reference
- **World Building**: Maintain established physics and lore
- **Tone**: Consistent sci-fi mystery throughout
- **Pacing**: Balance between action, description, and introspection

### **Revision Process**
```
┌─────────────────┐    ┌──────────────────┐    ┌─────────────────┐
│   Initial       │───▶│   Author         │───▶│   Final         │
│   Feedback      │    │   Revisions      │    │   Version       │
└─────────────────┘    └──────────────────┘    └─────────────────┘
```

**Revision Levels:**
- **Level 1**: Minor fixes (typos, grammar)
- **Level 2**: Content improvements (descriptions, dialogue)
- **Level 3**: Structural changes (plot, character development)

## **💡 Best Practices**

### **Writing Workflow**
1. **Start with Structure**: Outline chapter beats before expanding
2. **Character First**: Ensure voices match before prose
3. **Sensory Details**: Add specific sights, sounds, feelings
4. **Mystery Building**: Layer creepy elements gradually
5. **ALEX Evolution**: Show progression from AI to human-like

### **Collaboration Tips**
1. **Clear Communication**: Be specific about needs and feedback
2. **Respect Expertise**: Trust each other's strengths
3. **Regular Check-ins**: Maintain momentum with daily updates
4. **Celebrate Wins**: Acknowledge progress and good work
5. **Learn Together**: Use challenges as growth opportunities

### **Quality Focus**
1. **Reference Original**: Always check against transcript
2. **Voice Consistency**: Regular character voice audits
3. **Pacing Balance**: Mix action, description, and introspection
4. **Mystery Enhancement**: Build suspense through atmosphere
5. **Human Touch**: Add vulnerability and growth to characters
