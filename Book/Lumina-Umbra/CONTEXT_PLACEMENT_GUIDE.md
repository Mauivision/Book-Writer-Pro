# Context Placement Guide - Lumina-Umbra

Use this sheet whenever you paste raw notes, worldbuilding fragments, or transcript chunks.  
Goal: decide where each item belongs before drafting.

## Placement Heuristics

1. **If it changes character trust**, place in Act I or early Act II.
2. **If it reveals system truth**, place near chapter endings.
3. **If it resolves a moral argument**, reserve for Act III.
4. **If it only explains lore**, attach to scene texture, not exposition blocks.
