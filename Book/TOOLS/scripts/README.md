# 📜 CONSISTENCY CHECKER SCRIPTS

## 🔧 **Available Scripts**

### **consistency-checker.js**
Comprehensive consistency checker for all books.

**Features**:
- Character name consistency checking
- Formatting standard verification
- Timeline consistency checks
- Cross-book analysis

**Usage**:
```bash
node consistency-checker.js
```

---

### **character-verifier.js**
Verifies character details match between profiles and chapters.

**Features**:
- Character profile verification
- Physical description consistency
- Character detail matching

**Usage**:
```bash
node character-verifier.js
```

---

## 📋 **Requirements**

- Node.js installed
- Access to Book directory structure

---

## 📊 **Output**

Both scripts generate:
- Issue reports with severity levels
- Specific chapter and character references
- Suggestions for fixes
- Summary statistics

---

**Use these tools to maintain consistency across your collection!** ✅
