## Side Story Branch — Crystal Gauntlet Deep Lore

### What this is
This folder contains an **optional “deep lore” side story** that expands the mythic backbone of the single **Crystal Gauntlet of Lumora** and how it’s integrated into:
- **Lumora: The Eternal Gauntlet** (main manuscript in `../CHAPTERS/`)
- **Gears of Lumora: The Steampunk Eternal Gauntlet** (builder/steampunk layer)

It’s written to **enrich** the main story without forcing hard retcons. Think: *unlockable codex / secret route / season-two myth arc.*

### Canon rules (so we don’t break Volume 1)
- **Volume 1 stays “game-logic visible”**: UI, jealousy aggro, trials, watchers, patch notes.
- This side story reveals the **why** behind those mechanics: **Architect-era world infrastructure** presenting itself as “System” behavior.
- Nothing here should contradict what’s already on-page; it should **reframe** it.

### The big reveals this branch supports
- **Architects**: extinct ethereal builders; reality-as-brass-and-aether worldview.
- **First Equinox**: cataclysmic alignment; World Core fracture; cyan aetherite fragment becomes the Gauntlet seed.
- **The Gauntlet**: a **sentient emergency balance mechanism** that selects an outsider host to restore equilibrium.
- **Overdrive Surge**: not “power fantasy,” but a dangerous local **rewrite** that forces temporary Light+Veil unity.
- **Sunny**: a fragmented Architect-era monitoring intelligence (the “tutorial” mask is a UI wrapper).
- **Elara**: descendant of a hidden Architect bloodline; resonance explains why she “finds” Haruto.

### Where it plugs into the main manuscript
Recommended “unlock” points:
- After `CHAPTERS/Chapter-16-Unity-Trial-Mirror-Lies.md` (Watcher + mirror logic makes the first codex reveal feel earned)
- Or as a Season/Volume break bonus chapter (between Volume 1 and Volume 2)

### Files
- `OUTLINE.md`: the full mini-arc plan (episodes, reveals, and how to reference it in the main story)
- `CHAPTERS/`: prose chapters (codex scenes + myth flashbacks + present-day reveal beats)
