# Mission Template

Copy this structure for each `ch##-*.md` file.

```markdown
# Mission {ID} — {Title}

| Field | Value |
|-------|-------|
| Chapter | {NN} |
| Arc | {Arc name} |
| Manuscript | `CHAPTERS/Chapter-{NN}-*.md` |
| Quest ID | `{q_id}` or — |
| Zones | `{zone_ids}` |
| Est. playtime | {minutes} |
| Prerequisites | {mission IDs} |

## Narrative objective
{one paragraph}

## Gameplay objective
{bulleted list}

## Scenes
| ID | Type | Summary |
|----|------|---------|

## Start state
## End state
## Fail states

## Characters
## Key objects

## Bond / faction deltas
## Rewards & unlocks
## Reactivity flags
## Branch hooks
## Implementation notes
```
