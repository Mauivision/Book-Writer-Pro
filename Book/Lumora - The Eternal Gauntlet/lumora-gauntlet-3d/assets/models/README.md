# Imported Models (.glb)

This folder is for final exported assets from Blender.

## Current State

Still in greybox phase. No external models imported yet.

## Workflow

1. Model in Blender (assets/blender/)
2. Export as .glb here
3. Assign Lumora palette materials from assets/materials/
4. Replace inline meshes in scenes/

Example:
- SM_CrystalCluster_Improved.glb
- SK_Velvet_Prototype.glb
