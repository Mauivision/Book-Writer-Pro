LUMORA GAUNTLET 3D - SANDBOX BUILD
==================================

HOW TO RUN
----------
1. Double-click RUN_SANDBOX.bat
   (or open the folder in Godot 4 and press Play)

2. On the title screen, click "Enter the Meadow"

CONTROLS
--------
Movement:
- WASD / Arrow Keys = Move
- Space = Dash

World Interaction:
- E = Interact / Harvest / Talk (stand inside glowing nodes or near NPCs)

Sandbox Building (Press B to toggle - costs materials!):
- B              = Toggle Build Mode
- 1 / 2 / 3      = Select build object (see costs below)
- Left Click     = Place object (only succeeds if you have the harvested materials)
- R              = Rotate selected object
- Right Click    = Delete object under cursor

THE CORE LOOP
-------------
Explore the world → Press E on glowing harvest nodes (Verdant Crystals, Ruin Piles, Echo Veins) to gather materials → Toggle B and build only what you can afford.

**Your buildings and harvested nodes now persist.** Leave a zone and come back — your structures are still there. Quit and relaunch the game — the world remembers what you built and what you took.

Talk to Velvet (near the Workbench in the starting Meadow) for story.

CURRENT FEATURES
----------------
- 4 connected explorable zones with ruins and elevation
- Real resource economy: harvesting is required before building
- 3 placeables with material costs (Crystal Cluster, Stone Platform, Small Ruin)
- First story NPC: Velvet (dialogue drawn from Lumora canon)
- Workbench (E to attempt crafting)
- Zone exits (now functional) + camera follow
- **Persistence**: Player-built objects + harvested nodes survive zone hops and full game restarts (saved to user://lumora_builds/)

This is the living 3D sandbox extension of the Lumora: The Eternal Gauntlet book. Shape the world only after you have walked it.
