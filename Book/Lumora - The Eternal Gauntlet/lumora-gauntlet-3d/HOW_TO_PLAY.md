HOW TO PLAY LUMORA GAUNTLET (Including Sandbox Mode)
====================================================

1. Open Godot 4 and import the folder:
   lumora-gauntlet-3d

2. Press Play.

3. On the Title Screen, click "Enter the Meadow".

4. Normal Controls:
   - WASD / Arrow Keys = Move
   - Space = Dash

5. Sandbox / Build Mode (NEW):
   - Press **B** to toggle Build Mode on/off
   - While in Build Mode:
     - Press **1, 2, or 3** to select different objects
     - Left Click to place the selected object
     - Move your mouse to position the preview

Available build objects:
1. Crystal Cluster
2. Stone Platform  
3. Small Ruin piece

This is the beginning of the sandbox system. You can now freely build and shape the world while exploring.

More objects and features (resource costs, saving builds, etc.) will be added next.
