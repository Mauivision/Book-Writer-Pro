## Quick use

- **Adding a spirit guide to a book:** Read the plan, then the spirit guide doc. Add waypoint passages at act/book boundaries; add the “Learning to Love to Live” chapter where the story has just paid a heavy cost.
- **Refactoring for all readers:** Use the checklist in the plan (Section 4); run it on key chapters first, then the full manuscript.
- **Chakra / depth of reality in story:** Use the 12-chakra reference for symbolism or a line or two from the guide about “layers” or “pillars.”
