# Production Quick Start

## After Editing Chapters

Run:

```bash
npm run sync-production
```

That updates PDFs, story build files, and the dashboard for **modified books only**.

---

## What Gets Updated

- PDFs (print-ready)
- Story build files
- Production dashboard
- Status tracking

---

## Watch Mode (optional)

To auto-update on every save:

```bash
npm run watch-production
```

---

**Remember**: Always sync after editing chapter content.
